# Vue Ollama Backend

Express.js backend with TypeScript and Drizzle ORM for managing conversations and chat streaming with Ollama.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

To start the app in dev mode with hot reload.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm start`

For production mode (builds TypeScript and starts the server)

### `npm run test`

Run the test cases.

### `npm run build:ts`

Build TypeScript to JavaScript

### `npm run watch:ts`

Watch TypeScript files and rebuild on changes

## Tech Stack

- **Express.js** - Web framework
- **TypeScript** - Type-safe JavaScript
- **Drizzle ORM** - TypeScript ORM for database operations
- **Ollama** - Local LLM integration
- **SQLite** - Database (via libSQL)
